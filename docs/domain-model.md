# Domain foundation

An **institution** is a recognised actor; an **authority** is its power to declare, allocate, certify, route, admit, revoke, delegate, expose, mirror, or federate resources in scope. An authority is not CoreDNS, step-ca, Keycloak, PostgreSQL, nftables, or any service. A **mandate** bounds an authority's actions, resource classes, jurisdiction, validity, and constraints. Protocol surfaces may later materialise this meaning but are not its source.

World intent is canonical. Capabilities describe needs. Provider bindings are bounded, replaceable choices. Observed state and reconciliation do not exist in v0.1. Real-internet posture composes independently with cross-world posture. Peering imports suffix reachability/discovery, never trust. Federation declarations selectively import/export an explicit authority surface; federation execution and PKI cross-signing are not implemented.

Implemented: strict parsing, semantic diagnostics, defaults, resolver derivation, manifest/graph generation, explanations. Proposed later: compiler and observed state. Deferred: every server, network, durable store, provider execution, and security operation listed in the roadmap.
