# ADR 0001: NetSovereign as an authority-autonomous internet runtime
Status: Accepted for v0.1

Authority is first-class because sovereignty is recognised institutional power, not possession of software. Authorities are not services: naming is not CoreDNS, trust is not a CA product, identity is not an IdP, a registry is not a database, and transit is not a firewall. Gateway modes therefore describe boundary policy postures rather than firewall presets.

Peering imports reachability and discovery only and never shared trust. Federation means selective, explicit authority import/export—not connectivity—and this model does not execute federation or assume PKI cross-signing. Persistent self-hosted state will matter to later operational autonomy, but all persistence is deferred.

A coherent minimal world needs powers for world-root, naming, numbering, organisation and naming registries, registrar, trust, platform and in-world identity, transit, mail, and service catalogue. They are operated by a default administration institution; mail and catalogue start deferred. These defaults assert no services exist.
